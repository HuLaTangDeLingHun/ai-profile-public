# ai-profile-public

个人 AI 偏好的**公开脱敏镜像**。

## 为什么有这个仓

网页版 AI（ChatGPT、Gemini、豆包等）读不到私有仓库，但可以联网读公开页面。
这个仓库就是给它们的：把「怎么跟我说话、按什么规则输出」公开出来，同时**不含任何身份信息、联系方式、经营数据**。

完整档案在私有仓库，只对本地能跑 git 的工具开放。这一层拆分是刻意的——隐私和可用性不能同时最大化，只能分层。

## 内容

| 文件 | 作用 |
| --- | --- |
| `AGENTS.md` | 入口，说明使用者画像和读取顺序 |
| `style.md` | 写作与表达偏好 |
| `rules.md` | 可执行规则与禁止事项 |

## 怎么用

把仓库地址给 AI，让它读 `AGENTS.md`；或者直接复制 `style.md` + `rules.md` 的内容粘进对话开头。

## 承诺

本仓库不含：真实姓名、联系方式、住址、账号凭据、具体财务数据、可识别到个人的经营信息。
如果哪天需要加这类内容，加在私有仓，不要加在这里。
